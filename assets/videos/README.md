# Video assets

This directory is reserved for original video files from the source board.

At the extraction time, Pinterest exposed poster/image CDN assets but did not expose downloadable MP4 URLs in the board HTML or sampled pin pages. No fake, recompressed, or screen-recorded video files were added. The source board URL and pin IDs are preserved in `metadata/manifest.json` and `metadata/pin_ids.txt` for a later authenticated export.
